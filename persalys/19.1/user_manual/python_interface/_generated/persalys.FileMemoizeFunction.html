FileMemoizeFunction¶

class persalys.FileMemoizeFunction(*args)¶

Function proxy with a CSV file cache.

When this function is evaluated, it calls the openturns.Function passed as argument, and caches values with CSV files.

Parameters:
functionFunction

Delegate function

input_filestr

Input CSV file name

output_filestr

Output CSV file name
